📋 Documentação da API - Dashboard MCP Server
🏠 Base URL
text

http://localhost:8081/api/v1

🔐 Autenticação

Todas as rotas (exceto /login) requerem um token JWT no header:
text

Authorization: Bearer <seu_token_jwt>

📍 Endpoints
1. Login

POST /login

Request Body:
json

{
  "email": "admin@admin.com",
  "password": "admin123"
}

Response (200 OK):
json

{
  "success": true,
  "message": "Login successful",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "email": "admin@admin.com"
    }
  }
}

Error (401):
json

{
  "success": false,
  "error": "Invalid credentials"
}

3. Pedidos
3.1 Listar Pedidos

GET /pedidos?page=1&limit=20&status=confirmado&cliente_id=1&data_inicio=2026-01-01&data_fim=2026-01-31

Query Params:
Parâmetro	Tipo	Obrigatório	Descrição
page	int	❌	Página (default: 1)
limit	int	❌	Itens por página (default: 20, max: 100)
status	string	❌	Filtro por status (pendente, confirmado, preparando, entregue, cancelado)
cliente_id	int	❌	Filtro por cliente
data_inicio	date	❌	Data inicial (YYYY-MM-DD)
data_fim	date	❌	Data final (YYYY-MM-DD)

3.3 Atualizar Status do Pedido

PATCH /pedidos/{id}/status

Request Body:
json

{
  "status": "confirmado"
}

Status válidos: pendente, confirmado, preparando, entregue, cancelado

Response (200 OK):
json

{
  "success": true,
  "message": "Order status updated successfully",
  "data": {
    "id": 1,
    "status": "confirmado",
    "updated_at": "2026-08-12T10:05:00Z"
    // ... dados completos do pedido
  }
}

📊 Resumo dos Endpoints
Método	Endpoint	Autenticação	Descrição
POST	/login	❌	Login
GET	/dashboard	✅	Dashboard
GET	/pedidos	✅	Listar pedidos
GET	/pedidos/{id}	✅	Detalhe pedido
PATCH	/pedidos/{id}/status	✅	Atualizar status
GET	/clientes	✅	Listar clientes
GET	/clientes/{id}	✅	Detalhe cliente
GET	/clientes/{id}/pedidos	✅	Pedidos do cliente
GET	/clientes/{id}/enderecos	✅	Endereços do cliente
GET	/produtos	✅	Listar produtos
GET	/produtos/{id}	✅	Detalhe produto
GET	/health	❌	Health check
GET	/ready	❌	Readiness check
GET	/status	❌	Status detalhado
